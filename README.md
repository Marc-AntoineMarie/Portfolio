# Portfolio de Marc-Antoine Marie

## Description

Ce projet est un **portfolio personnel** de Marc-Antoine Marie, étudiant en **BTS SIO SLAM**, développé en **PHP**, **HTML5**, **CSS3** et **JavaScript**. Il présente les différentes sections : accueil, CV, BTS SIO SLAM, compétences, réalisations, veille technologique et contact.

## Fonctionnalités

- **Page d'accueil** avec animation VANTA.js (effet `waves`) et introduction rapide à ses compétences ([github.com](https://github.com/Marc-AntoineMarie/Portfolio/blob/main/pages/index.php))
- **Navigation responsive** avec burger menu et animation de la barre de navigation ([github.com](https://github.com/Marc-AntoineMarie/Portfolio/blob/main/include/header/navbar.php))
- **Section CV** téléchargeable au format PDF depuis `assets/cv_Marie_Marc-Antoine_Bachelor_dev.pdf` ([github.com](https://github.com/Marc-AntoineMarie/Portfolio/tree/main/assets))
- **Section BTS SIO SLAM** présentant les travaux et annexes du cursus ([github.com](https://github.com/Marc-AntoineMarie/Portfolio/tree/main/assets))
- **Section Compétences** listant les compétences techniques et méthodologiques ([github.com](https://github.com/Marc-AntoineMarie/Portfolio/tree/main/js))
- **Section Projets** illustrant ses réalisations avec des descriptions et liens ([github.com](https://github.com/Marc-AntoineMarie/Portfolio/tree/main/pages))
- **Section Veille Technologique** pour partager les tendances et ressources ([github.com](https://github.com/Marc-AntoineMarie/Portfolio/tree/main/pages))
- **Formulaire de contact** pour faciliter les échanges, relié à `pages/contact.php` et `assets` pour documents annexes ([github.com](https://github.com/Marc-AntoineMarie/Portfolio/tree/main/pages))
- **Footer** interactif avec mentions légales en modal et liens vers GitHub/LinkedIn ([github.com](https://github.com/Marc-AntoineMarie/Portfolio/blob/main/include/footer/footer.php))

## Technologies utilisées

- **Backend** : PHP (inclusion de headers et footers via `include/header/navbar.php` et `include/footer/footer.php`) ([github.com](https://github.com/Marc-AntoineMarie/Portfolio/blob/main/include/footer/footer.php), [github.com](https://github.com/Marc-AntoineMarie/Portfolio/blob/main/include/header/navbar.php))
- **Frontend** : HTML5, CSS3 (fichiers dans `css/include` et `css/pages`) ([github.com](https://github.com/Marc-AntoineMarie/Portfolio/tree/main/css))
- **JavaScript** : scripts de navigation (`js/navbar.js`), animation VANTA (`js/vantawaves.js`), et autres fonctionnalités (`js/main.js`) ([github.com](https://github.com/Marc-AntoineMarie/Portfolio/tree/main/js))
- **Libraries** : [Three.js](https://threejs.org/), [VANTA.js](https://vantajs.com/), [Font Awesome](https://fontawesome.com/) pour les icônes

## Structure du projet

```
Portfolio/
├─ assets/                 # CV, PDF, images et documents annexes ([github.com](https://github.com/Marc-AntoineMarie/Portfolio/tree/main/assets))
├─ css/

│  └─ pages/               # Styles pour chaque page (e.g., style.css) ([github.com](https://github.com/Marc-AntoineMarie/Portfolio/blob/main/pages/index.php))

```
